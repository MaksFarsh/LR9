# Домашнее задание: Вывод графического изображения (ASCII-графика)

## 1. Алгоритм

1. Начало.
2. Инициализация глобальных констант для настройки размера фигуры: `L1 = 7`, `L2 = 14`.
3. Запуск внешнего цикла по строкам: переменная `l` от `0` до `L2 + 1` (включительно).
4. Внутри внешнего цикла выполняются четыре последовательных вложенных цикла для формирования текущей строки:
   * **Первый цикл (`w1`)**: вывод пробелов для отступа слева.
   * **Второй цикл (`v1`)**: вывод символов `*` (формирование верхней/центральной расширяющейся части фигуры).
   * **Третий цикл (`w2`)**: вывод пробелов в середине (разделение элементов).
   * **Четвертый цикл (`v2`)**: вывод символов `*` (формирование нижней/правой части фигуры, выполняется при условии `l > 7`).
5. Переход на новую строку (`printf("\n")`).
6. Конец (после завершения внешнего цикла).

## 3. Реализация программы

```c
#include <stdio.h>
#include <math.h>

#define L1 7
#define L2 14

void main() {
    for (int l=0; l <= L2+1; l++) {
        for (int w1 = L1; w1 >= l; w1--)
            printf(" ");
        for (int v1 = l; v1 <= l + l*2 && l+l*2 <= L2+1; v1++)
            printf("*");
        for (int w2 = L1; w2 <= l && l; w2++)
            printf(" ");
        for (int v2 = L2*2+1; v2 >= l * 2 - 1 && l > 7; v2--)
            printf("*");
        printf("\n");
    }
}
