# Домашнее задание: Вывод фигуры с помощью вложенных циклов

## 1. Алгоритм

1. Начало.
2. Инициализация констант: `L1 = 7` (отступ), `L2 = 14` (ширина).
3. Запуск внешнего цикла для перебора строк: `l` от 0 до `L2 + 1` (то есть до 15 включительно).
4. Внутри внешнего цикла выполняются четыре последовательных вложенных цикла:
   * **Цикл 1 (пробелы слева):** переменная `w1` меняется от `L1` до `l`. Выводит пробелы для формирования отступа в верхней половине фигуры.
   * **Цикл 2 (верхние звездочки):** переменная `v1` меняется от 1 до `1 + l * 2` (при условии, что это число не превышает `L2 + 1`). Выводит расширяющуюся часть фигуры.
   * **Цикл 3 (пробелы внутри):** переменная `w2` меняется от `L1` до `l` (при условии `l > 0`). Выводит пробелы для формирования пустоты внутри фигуры.
   * **Цикл 4 (нижние звездочки):** переменная `v2` меняется от `L2*2+1` вниз до `l*2-1` (при условии `l > 7`). Выводит сужающуюся часть фигуры (нижняя половина).
5. Переход на новую строку с помощью `printf("\n")`.
6. Конец.

## 3. Реализация программы

```c
#include <stdio.h>
#include <math.h>
#define L1 7
#define L2 14

void main() {
    for (int l=0; l <= L2+1; l++) {
        for (int w1 = L1; w1 >= l; w1--)
            printf(" ");
        for (int v1 = 1; v1 <= 1 + l * 2 && 1+l*2 <= L2+1; v1++)
            printf("*");
        for (int w2 = L1; w2 <= l && l; w2++)
            printf(" ");
        for (int v2 = L2*2+1; v2 >= l * 2 - 1 && l > 7; v2--)
            printf("*");
        printf("\n");
    }
}
```
